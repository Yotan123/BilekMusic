# BilekMusic

**BilekMusic** adalah desktop music client modern yang dibangun dengan Vite, React, dan Tailwind CSS. Proyek ini menghadirkan pengalaman mendengarkan musik yang imersif dengan antarmuka bersih, lirik tersinkronisasi, dan desain yang terinspirasi dari Apple Music.

## ✨ Fitur Utama

- 🎵 **Pemutar Musik Desktop** — Antarmuka sidebar + bottom player bar yang responsif.
- 🎤 **Lirik Tersinkronisasi** — Nikmati lirik yang bergulir otomatis sesuai lagu.
- 👤 **Profil Pengguna** — Halaman profil untuk personalisasi pengalaman mendengarkan.
- 🔍 **Pencarian & Koleksi** — Jelajahi lagu, album, dan artis dengan mudah.
- 🎨 **Desain Modern** — Menggunakan Tailwind CSS dan Framer Motion untuk animasi halus.
- 🖥️ **Cross-Platform** — Dibangun dengan Electron untuk pengalaman desktop yang native.

## 🚀 Memulai untuk Pengembang

Ikuti langkah-langkah berikut jika Anda ingin menjalankan proyek dari source code.

### Prasyarat

- [Node.js](https://nodejs.org/) (versi 18 atau lebih baru)
- [npm](https://www.npmjs.com/) atau [yarn](https://yarnpkg.com/)

### Instalasi

```bash
# Clone repositori
git clone https://github.com/Yotan123/BilekMusic.git

# Masuk ke direktori proyek
cd BilekMusic

# Instal dependensi
npm install

# Jalankan dalam mode pengembangan
npm run dev
